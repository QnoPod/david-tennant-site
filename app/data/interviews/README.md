# インタビューデータの編集場所

- `catalog.ts`: タイトル、公開日、URL、サムネイル、説明、内容ジャンル、関連タグ
- `transcripts/`: 英語原文と日本語訳
- `loadInterview.ts`: catalogのslugと翻訳ファイルを接続
- `types.ts`: データ形式。通常は変更不要

追加手順と入力例はプロジェクト直下の `README.md` を参照してください。

`genres`には内容に合う日本語ジャンル（例: `作品・役づくり`、`共演者・関係性`）を設定します。
人物名や作品名などの固有名詞は、従来どおり`tags`へ設定してください。
